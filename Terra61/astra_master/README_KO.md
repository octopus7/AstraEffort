# Riverdale Central — 증기기관 시대 기차역

첨부 원화를 기준으로 제작한 게임용 모듈식 기차역입니다. 중앙 시계 홀, 돔 타워, 철골 유리 지붕, 플랫폼과 선로, 기관차·탄수차·객차, 역 소품을 개별 GLB로 제공하며 전체 조립본도 포함합니다.

## 열어 보기

- 전체 모델: `Riverdale_Station_assembled.glb`
- 개별 모델: `modules/` 아래 테마별 폴더
- 실제 모델 렌더: `previews/` 안의 PNG 5장
- 3D 미리보기: Python 3에서 `python start_viewer.py` 실행. 자동으로 열리는 브라우저에서 회전·확대·모듈 선택·지붕 숨기기·와이어 표시를 사용할 수 있습니다. 외부 CDN과 로그인은 필요 없습니다.
- 다른 정적 서버에서는 이 폴더를 루트로 제공하고 `web/index.html`을 열면 됩니다. 브라우저 보안 제한 때문에 HTML 파일 더블클릭보다 로컬 서버를 이용해 주세요.

## 제작 기준

실루엣에 필요한 돔, 아치, 지지 기둥, 차량의 큰 형상과 바퀴는 메시로 만들었습니다. 벽돌 이음새, 석재 표면, 창문 세부, 시계 숫자, 철제 문양, 리벳과 마모는 이미지 생성 텍스처로 표현합니다. 반복 부재는 메시와 재질을 공유합니다. 창문·시계·출입문·차량 측면에는 전용 텍스처 영역을 사용합니다.

GLB는 미터 단위의 glTF 2.0이며 Y축이 위입니다. 제작 스크립트의 좌표는 X=가로, Y=역 뒤쪽, Z=위이며, 각 모듈 루트에서 한 번만 glTF 축으로 변환합니다. `scene_layout.json`의 배치 좌표는 제작 좌표입니다.

- 플랫폼·선로·지붕 반복 간격: 8m
- 플랫폼 상면: Z=1m
- 레일 상면: Z=0.22m
- 열차 바퀴 하단: 모듈 Z=0m → 조립할 때 Z=0.22m 이동
- 선로 중심 간격: 1.435m
- 상세 치수와 폴리곤 수: 각 폴더 `manifest.json` 및 `asset_inventory.json`

## 재질과 엔진 가져오기

개별 GLB 안에 텍스처가 내장되어 있습니다. 원본 및 파생 맵은 `textures/`와 각 모듈 폴더에 함께 있습니다. Base Color는 색상 맵이며, Normal과 ORM은 데이터 맵입니다. ORM은 R=중립 AO, G=Roughness, B=Metallic 순서입니다. 노멀과 거칠기 맵은 생성한 색상 이미지에서 근사한 것으로 스캔 데이터는 아닙니다.

게임 엔진에서는 개별 모듈을 정적 메시로 가져온 뒤 반복 배치하거나 전체 GLB를 장면으로 가져올 수 있습니다. 엔진의 단위·축 자동 변환을 확인하고 중복으로 회전하지 마세요. 유리에는 알파 블렌딩, 가로등에는 발광 재질을 사용합니다. 사용할 엔진에 맞는 충돌체·라이트맵·LOD는 프로젝트에서 설정하세요.

이 묶음은 외관과 플랫폼 중심의 정적 환경입니다. 역사 내부의 완전한 실내, 승객 캐릭터와 열차 주행 애니메이션은 포함하지 않습니다. 원화의 장식 일부는 게임용으로 단순화되어 있습니다.

## 재생성

`src/`에는 각 모델 제작, 재질 준비, 탠전트 생성과 전체 조립 스크립트가 있습니다. Python 의존성은 `requirements.txt`에 기록했습니다. 모듈 생성 후 `python src/add_tangents.py 'modules/**/*.glb'`를 실행하고 `python src/assemble_station.py`로 전체 장면을 다시 조립합니다. `docs/image_prompts.json`은 이미지 생성 프롬프트, `references/`는 생성한 모델링 레퍼런스입니다.

웹 뷰어에는 Three.js가 포함되어 있으며 라이선스는 `web/vendor/THREE_LICENSE.txt`입니다. 검수 기록은 `reports/`에 있습니다.
