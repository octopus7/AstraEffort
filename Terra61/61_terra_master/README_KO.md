# Riverdale Central Station — 게임용 모듈 세트

증기기관 시대 역사를 원화에 맞춰 단순화한 정적 3D 환경입니다. 큰 실루엣을 메시로 만들고 벽돌, 석재, 바닥, 자갈, 노후 주철, 목재 및 작은 장식을 UV와 이미지 텍스처로 표현했습니다. 개별 레퍼런스와 실제 모델 렌더를 모두 포함합니다.

## 폴더 구성

- `assembled/riverdale_station.glb` — 역 전체를 조립한 GLB. 텍스처 내장. 20.7 MiB.
- `modules/` — 역사 정면, 캐노피, 광장, 지붕, 선로/승강장, 기관차, 석탄차, 객차, 조명, 벤치, 수하물 카트, 벽시계, 번호판, 상자, 통의 개별 GLB. 각 폴더에는 텍스처, 렌더, 생성 코드와 설명이 있습니다.
- `references/` — 제공된 원화와 각 모듈별 생성 레퍼런스.
- `materials/` — AI 생성 기반 재질 원본.
- `previews/` — 실제 조립 GLB로 렌더한 전체·정면·내부·상단 이미지.
- `viewer/` — 인터넷 연결 없이 조립 GLB를 회전하며 볼 수 있는 로컬 뷰어.

## 미리보기 실행

압축을 푼 뒤 Python 3가 설치되어 있다면 `python viewer/serve.py`를 실행하세요. 브라우저가 열리고, 마우스 또는 터치로 회전·확대할 수 있습니다. 로컬 파일 접근 제한 때문에 `index.html`을 직접 열기보다는 이 실행 방법을 사용하세요. 뷰어는 포함된 Three.js를 사용하며 외부 서버나 CDN에 연결하지 않습니다.

## 조립 규격

- glTF 좌표 기준 Y가 위, 단위는 미터입니다. 원점을 선로 바닥에 두었습니다.
- 지붕과 선로는 6m 길이 구간을 8회 반복하여 조립했습니다. 선로 중심은 X=−4m, +4m이고 궤간은 1.435m입니다.
- 역 전체 경계는 약 X −10~30m, Y −0.2~12.5m, Z −10~48.27m입니다.
- 조립본은 서로 공유하는 메시 85개, 인스턴스 249개, 고유 삼각형 98,124개입니다. 현재 배치가 실제로 그리는 삼각형은 약 214,042개입니다.
- 조립 GLB의 불투명 베이스 컬러는 원본 해상도를 유지한 JPEG 품질 94로 압축했습니다. 알파 텍스처와 메시, UV, 배치에는 변경을 주지 않았습니다. 개별 모듈에는 원래 텍스처가 유지됩니다.

## 사용 시 참고

- 모델은 정적입니다. 열차 바퀴·연결봉 애니메이션, 실제 조명, 연기, 사람, 충돌체는 포함하지 않았습니다. 객차는 창 너머로 보이는 간단한 내부만 있습니다.
- 표면 디테일은 AI 생성과 절차 생성 베이스 컬러를 혼용합니다. 별도의 완성된 노멀·러프니스·메탈릭 텍스처 세트는 포함하지 않습니다.
- 원화의 복잡한 장식과 도시 배경을 단순화한 게임용 모델입니다. 내부 역사 공간과 주변 도시는 완성 모델에 포함되지 않습니다.
- GLB와 내장 이미지, 메시/좌표를 다시 읽어 확인하고 Three.js GLTFLoader에서 조립본을 검수했습니다. Unreal 등 특정 엔진 임포트 및 Khronos 공식 검증은 실행하지 않았습니다. 엔진으로 옮길 때 좌표축 변환, 유리 재질, 조명과 충돌을 확인하세요.
