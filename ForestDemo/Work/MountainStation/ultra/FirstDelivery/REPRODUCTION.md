# Authoritative final source

`SourceArt/AlderPass.blend` and its 47 FBX exports are the final authored geometry. `export_final.py` re-exports this final source without changing geometry. `build_unreal.py` constructs the map from those FBX files in a private baseline project with the same ForestDemo module; it is never run against the shared project.

The initial `build_art.py` and the `finalize_art.py`, `refine_access.py`, `fix_ramp_winding.py`, `refine_presentation.py`, and `final_geometry_fixes.py` files are retained as production history. Some refinements are applied to an already-authored Blender file and are **not idempotent**. Do not replay these revision scripts on the final .blend. Use `export_final.py` for a clean final export.

Run every private Unreal process through `Work/Tools/Run-UnrealIsolated.ps1`, supplying this assignment's project, log and timing paths. `run_review.py` reloads the map, allows world initialization, records collision and recursive dependency evidence, runs actual PIE checks, then renders the four comparison PNGs. It uses a real RHI and must not be launched with NullRHI. SceneCapture2D output contains no editor overlays. The top-down rotation uses named pitch/yaw/roll arguments because positional Rotator construction does not follow that order in the UE Python binding.

`runtime_checks.py` verifies default PlayerController/DefaultPawn possession, the arrival spawn, swept movement along the graded ramp, blocking against the platform side, and a transient native BeginPlay lifecycle probe. This adds no gameplay class or asset to the delivered map. The baseline ScreenDebugLogger implementation and binaries are unchanged.

Post-review blocking evidence lives in `BlockingSupplement/`. Its `Before/` records preserve the first ready timestamp and original assertions. The strict check requires a clear start sphere, positive actual Pawn travel, and the Pawn movement's own non-initial blocking HitResult with its exact actor/component/mesh. A same-radius Pawn-profile sphere trace corroborates it. Terrain inspection enumerates `get_num_sections(0)` and reads actual LOD0 triangle buffers, rather than assuming material slots imply mesh sections. `finish.py` preserves first-delivery timing and records supplement timing separately; do not rerun `finalize_report.py` to erase that history.

`publish.py` is a final gate: it requires successful strict collision/dependency and runtime records, author-inspected screenshot hashes, exact PNG dimensions, no external actor/object packages and no BuiltData. It copies only this assignment's asset folder and map, then checks SHA-256 equality.

Technical references: [UE 5.7 SceneCaptureComponent2D](https://dev.epicgames.com/documentation/en-us/unreal-engine/python-api/class/SceneCaptureComponent2D?application_version=5.7), [RenderingLibrary](https://dev.epicgames.com/documentation/en-us/unreal-engine/python-api/class/RenderingLibrary?application_version=5.7), [LevelEditorSubsystem](https://dev.epicgames.com/documentation/en-us/unreal-engine/python-api/class/LevelEditorSubsystem?application_version=5.7), [AssetRegistryDependencyOptions](https://dev.epicgames.com/documentation/en-us/unreal-engine/python-api/class/AssetRegistryDependencyOptions?application_version=5.7). The installed engine headers were also consulted for exact binding behavior. There are no external artistic references or borrowed scene resources.
