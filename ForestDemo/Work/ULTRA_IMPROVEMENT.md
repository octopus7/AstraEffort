# Ultra 자가 개선 결과 보고서

현재 상태: **예약됨 — 기존 8개 작업의 완료를 기다리는 중**.

이 문서는 Forest와 MountainStation의 ultra 후속 자가 개선만 기록합니다.
현재 추론 강도 비교 실험은 `SUPERVISION.md`에서 마무리한 뒤 고정하며,
자가 개선 계획·진행·결과·시간·토큰을 해당 비교 문서에 추가하지 않습니다.
현재 문서는 보고서 틀이며, 자가 개선을 시작하거나 완료했다는 의미가 아닙니다.

## 시작 조건과 기록 보존

1. 두 테마의 최초 작업 및 UV·이미지 생성 텍스처 보강 8개를 모두 검증하고 개별 커밋합니다.
2. 필요한 수정, 최종 8맵 통합, 재로드·의존성 검증을 완료합니다.
3. 기존 비교 보고서의 실제 스크린샷·수행 시간·토큰 분석을 마무리하고 커밋합니다.
4. 비교 보고서와 연결된 증거·이미지·토큰 스냅샷의 기준 커밋과 해시를 보존합니다.
5. 기존 Forest ultra 및 MountainStation ultra 대화에만 자가 개선을 지시합니다.

기존 모델과 ultra 추론 강도를 유지합니다. 각 대화는 자기 장면을 검토하여
개선 우선순위를 정하고 구현·검증합니다. 다른 테마나 추론 강도의 자산·코드는
읽거나 재사용하지 않습니다. 감독자가 작업별 커밋을 관리합니다.
medium/high/xhigh 결과 및 기존 비교 증거는 보존합니다.

## 기록 원칙

장면 증거는 실제 UE 렌더만 사용합니다. 새 스크린샷은 각자의
`SelfImprovement/Screenshots/`에 저장하고 기존 `FirstDelivery/TexturePass`
증거는 덮어쓰지 않습니다. 물리적 시뮬레이션과 예술적 근사는 구분합니다.

이 단계의 토큰 스냅샷은 `ForestDemo/Work/UltraImprovementAccounting/`에
별도로 저장합니다. 집계 도구의 `-NoWrite` 출력을 사용하여 고정된 비교 보고서와
`token_usage.json`을 수정하지 않습니다. 동일 세션의 누적값 차이를 기준으로
본 대화와 검증된 하위 에이전트를 구분하고 미확인 수치는 0으로 처리하지 않습니다.
토큰을 청구 금액으로 임의 환산하지 않습니다.

비교 실험의 고정 기준, 실제 시작·완료 시각, 수치와 커밋은 확인된 뒤에만 기록합니다.
