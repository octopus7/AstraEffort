# 주방 복셀 20종

크림색·세이지 그린·밝은 목재색으로 만든 가정용 주방 세트입니다. 각 모델에 large와 half가 있으며, 제품 산출물은 **VOX 원본 40개와 실제 렌더 PNG 40장**입니다. 제작 소스, 메타데이터, 검증·촬영 기록을 함께 보존합니다.

[20종 half 모음 이미지](delivery/overview_half.png) · [전체 파일 목록과 SHA256](delivery/manifest.json) · [최종 취합 검사](delivery/validation.json)

모음 이미지의 각 칸은 해당 물건에 맞춰 따로 촬영한 프리뷰입니다. 서로 같은 물리적 축척으로 배열한 장면이 아닙니다. 원래 768×768 개별 프리뷰는 모두 보존됩니다.

개별 파일은 `묶음/assets/모델명/{large,half}/`에 있습니다. 각 폴더의 `모델명.vox`가 복셀 원본이고, `preview.png`가 해당 저장 원본을 다시 읽어 만든 실제 렌더입니다. `metadata.json`에 격자·복셀 크기·팔레트·해시가 있습니다.

large의 최장 축은 128칸이며 각 축은 짝수입니다. half는 각 축의 칸 수를 정확히 절반으로 줄이고 복셀의 미터 크기를 두 배로 하여 동일한 물리적 격자 크기를 유지합니다. 냉장고와 주전자 등의 실제 크기 차이는 모델별 메타데이터에 반영했습니다.

각 담당자가 저장된 VOX를 검증하고 최종 프리뷰 전부를 직접 확인했습니다. 이후 다른 담당자가 동일 파일을 읽어 해시·격자·축소·중요 공간을 확인하고 최종 이미지 전부를 교차 검수했습니다. 세 묶음 모두 사양 및 시각·기술 검수 PASS이며, 세 생산 기록의 기능 검사 합계는 178개입니다. 실제 렌더는 Blender Cycles CPU, 768×768, 24 samples, AgX, 프로세스당 4스레드를 사용합니다.

정적 팔레트 복셀입니다. 유리 부분은 불투명 청회색으로 표현되며 half에서 일부 얇은 장식선은 단순해집니다. 모델마다 정해진 한 방향에서 촬영하므로 뒤쪽이나 밑면의 모든 구조가 이미지에 보이지는 않습니다. 이 범위의 기능 공간은 저장 복셀 검사로 보완했습니다. 이번 산출물 범위는 VOX와 프리뷰이며 교환 메시·엔진 자산은 생성하지 않았습니다.

정확히 세 gpt-6-astra/max 서브에이전트가 형상·복셀·프리뷰·검수·모음 이미지를 제작했습니다. 메인 대화는 배분, 진행 기록과 검수 인계만 맡았습니다. Fast는 요청됐으나 서브에이전트 도구에 별도 지정 항목이 없어 적용을 주장하지 않습니다.

제작·교차 검수·취합의 실제 UTC/KST 시각과 소요 시간은 각 RESULT/STATUS/timing 및 delivery 기록에 나뉘어 있습니다. 세 작업은 병렬로 실행됐으므로 각 작업 시간을 더한 값은 전체 벽시계 시간이 아닙니다.
