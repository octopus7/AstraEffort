SSTO — 레퍼런스 기반 수직 착륙 우주선 외형 모델

주요 파일
  SSTO.glb               텍스처를 내장한 glTF 2.0 모델 (다른 파일 없이 사용 가능)
  SSTO.blend             편집 원본 / 텍스처 패킹 / 프리뷰 카메라와 조명 포함
  renders/hero.png       Blender 원본의 실제 Cycles 렌더
  renders/glb_reimport_front.png, rear.png, engines.png
                        최종 GLB를 새 세션에 다시 가져온 뒤 렌더한 검증 이미지
  validation/UV_layout_4096.png  부품별 색으로 표시한 실제 UV 배치
  validation/validation.json    자동 검사 결과와 최종 GLB SHA-256
  source/build_ssto.py          재생성 가능한 Blender Python 제작 스크립트
  source/imagegen_provenance.json  생성 이미지 원본 경로와 전체 프롬프트

형상과 편집
  높이 24.000 m, 전체 너비 약 10.996 m, 깊이 약 10.247 m.
  Blender에서는 Z가 위, -Y가 전면이며 원점은 착륙 접지면 중앙이다.
  GLB는 glTF 표준 Y-up으로 변환되어 내보내진다.
  11개 조립체, 160,164개 삼각형, 9개 PBR 재질.
  원본에는 패널과 부품 이름을 가진 버텍스 그룹이 남아 있다.
  GLB에는 조립체 구분이 유지되며, 세부 부품 편집에는 .blend 또는 제작 스크립트를 사용한다.
  레퍼런스의 외형을 해석한 모델이며 내부 단면, 리깅, 착륙 애니메이션은 제작 범위에 포함하지 않았다.
  레퍼런스에 비해 노즈가 조금 더 뾰족하고 착륙 페어링 형상은 단순화되어 있다.

UV와 텍스처
  좌우 부품을 포함해 전체 모델에 고유한 0–1 UV 공간을 사용한다.
  일반 부품은 면 방향에 따라 분리하고 면적 비율을 평균화했다.
  내부 압력 동체는 끝부분 뒤틀림을 피하도록 8개의 전개면으로 나눴다.
  4096px 아틀라스 기준 면적 가중 텍셀 밀도 중앙값은 약 57.67 px/m,
  표면적의 5–95백분위는 약 52.29–59.90 px/m이다.
  곡면의 투영 및 아주 작은 모서리에는 밀도 차이가 있다.
  아일랜드 패킹 여백 설정은 UV 0.003 (4K 기준 12.288px), 베이크 확장은 12px이다.
  여백은 패커에 지정한 값이며 최소 실제 간격을 별도로 수학적으로 측정한 값은 아니다.
  전체 텍스처 공간의 실제 면 점유율은 약 37.89%이며, 나머지는 패딩과 분리된 작은 면 사이 공간이다.

  내장 image_gen으로 아이보리 세라믹과 청회색 도장 텍스처를 각각 생성했다.
  실제 생성 원본은 각각 1254×1254 PNG이며 textures/에 보존되어 있다.
  원본을 UV에서 5배 반복 샘플링해 미세한 질감을 만든 다음,
  재질별 색상을 고유 UV에 조명 없이 베이크해 SSTO_BaseColor_4096.png에 통합했다.
  따라서 4K 파일은 생성 원본을 적용한 최종 UV 아틀라스이며 원본 자체가 4K로 생성된 것은 아니다.
  금속도와 거칠기는 재질 파라미터이며, 패널 경계와 노즐 등의 입체감은 실제 메시 형상이다.
  별도 노멀맵은 사용하지 않았다. GLB에는 최종 아틀라스 한 장이 완전히 내장되어 있다.

검증
  최종 4096×4096 내부 픽셀 검사: UV 겹침 0, 범위 이탈 0, 면적 0 UV 삼각형 0.
  픽셀보다 작은 교차까지 수학적으로 배제하는 검사는 아니며, 밉 단계별 패딩 검사는 하지 않았다.
  각 조립체의 경계/비다양체 에지 0.
  GLB 헤더, 이미지 내장, 전 프리미티브 UV, 재가져오기 조립체 수와 24m 높이를 확인했다.
  GLB에는 스튜디오 바닥, 카메라와 조명이 들어 있지 않다.
  실제 GLB 재가져오기 렌더 3장을 확인했다.
  별도 읽기 전용 검토에서도 내보내기/리소스 구성의 추가 중대 문제는 발견되지 않았다.

재생성 (Blender 4.5에서 별도 백그라운드 프로세스로 실행)
  blender --background --factory-startup --threads 4 --python source/build_ssto.py
  blender --background SSTO.blend --threads 4 --python source/validate_ssto.py
  source/build_ssto.py는 Blender/의 모델, 아틀라스, hero 렌더를 다시 생성한다.
  REF 이미지는 참조용으로만 읽었으며 수정하거나 모델에 포함하지 않았다.
