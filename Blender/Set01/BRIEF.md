# Set 01 production brief

User-approved assets: four-wheel cargo rover, biped service mech, arched workshop, water tank pumping station.

Style: rounded ends and corners, soft silhouettes, readable functional structures, simplified and friendly without childish decoration. No clouds, smileys, hearts or other ornamental cute motifs.

Workflow: the main agent generates exactly four final concept reference sheets sequentially into REF/Set01. Only after all four references exist, the main agent models one asset and three max-reasoning workers each model one other asset in parallel. No worker image generation.

Delivery: each asset has its own Blender/Set01/<asset>/ directory containing editable .blend, .glb and .fbx mesh exports, procedural source script, actual Blender preview renders and validation evidence. Export only asset geometry, not the studio floor/lights/cameras. Use meters, Z up, floor at Z=0. Materials should be named and preserve the reference palette. Include usable UV maps. Static models; no animation rig is promised.

Isolation: these are newly authorized independent assets, not Forest/MountainStation effort assignments. Do not inspect or change ForestDemo creative resources, existing Blender projects, existing REF images, the shared Blender MCP scene, or Git state. Run separate background Blender instances only. Scope every write to REF/Set01 and Blender/Set01.

Design discretion: faithfully reconstruct the approved generated reference's major silhouette and functional details; minor view inconsistencies may be resolved into coherent real geometry and documented. Use restrained warm ivory/sage/graphite materials with small orange functional accents.
